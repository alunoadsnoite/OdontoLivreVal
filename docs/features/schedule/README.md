# Agenda

A versão 0.3.0 permite marcar, remarcar e cancelar consultas de teste para pacientes fictícios já cadastrados. A agenda mostra um dia por vez, ordena as consultas por horário e mantém as canceladas no histórico do dia. O armazenamento impede duas consultas ativas no mesmo minuto.

A agenda compartilha o armazenamento criptografado de demonstração com Pacientes. A migração preserva os nomes e consultas das versões anteriores. Visualização mensal, retornos, lembretes e uso com dados clínicos dependem das próximas etapas.
