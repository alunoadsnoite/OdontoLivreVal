# Agenda

A agenda permite marcar, remarcar e cancelar consultas de teste para pacientes fictícios já cadastrados. Ela mostra um dia por vez, ordena as consultas por horário e mantém as canceladas no histórico do dia. O armazenamento impede duas consultas ativas no mesmo minuto.

A agenda compartilha o armazenamento criptografado de demonstração com Pacientes e Prontuário. A migração preserva os nomes e consultas das versões anteriores. O botão **Ver ficha do paciente** abre o prontuário, e **Abrir Pacientes** leva ao cadastro quando ainda não há pacientes.

Visualização mensal, duração de consulta, retornos, lembretes e uso com dados clínicos dependem das próximas etapas.
